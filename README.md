# Aura Studio — Salon Booking Website

A complete, production website for a hair & beauty salon, with real-time online appointment booking and an admin dashboard to manage them. Built and deployed solo as a demonstration of a full small-business web product.

**Live demo:** https://salon.vardevo.com

## What it does

- **Marketing site** — landing page, services, and pricing for a salon
- **Online booking** — customers pick a service and time; bookings are saved to a database instantly
- **Admin dashboard** — the owner sees and manages all incoming bookings in one place
- **24/7 lead capture** — every booking is stored, so no customer enquiry is lost

## Tech stack

- Front end: HTML5, CSS3 (custom, responsive)
- Backend / database: Supabase (PostgreSQL)
- Hosting: Vercel

## Pages

| Page | Purpose |
|------|---------|
| `index.html` | Landing page |
| `services.html` | Services & pricing |
| `book.html` | Appointment booking (writes to Supabase) |
| `admin.html` | Owner dashboard to view/manage bookings |
